# NDCycle (RamixEngine)

**NDCycle** — высокопроизводительное Android-приложение, разработанное с использованием Kotlin, Jetpack Compose и Google AI Studio. Оно создано для управления автоматическими циклами текстур, фоновыми службами и эмуляцией сенсорных жестов для рабочих процессов, связанных с PPSSPP.

##  Возможности

- **Автоматизированная смена текстур:** Упрощает и автоматизирует подмену фоновых текстур и ассетов для игровых конфигураций PPSSPP.
- **Продвинутые фоновые службы (`NDCycleService`):** Надежно работают в фоновом режиме, выполняя непрерывные циклы обработки и эмуляцию жестов без неожиданного завершения системы.
- **Современная архитектура Android:** Полностью написано на Kotlin и Jetpack Compose для создания плавного, отзывчивого и стильного интерфейса.
- **Максимальная производительность:** Спроектировано так, чтобы задействовать все ресурсы железа для тяжелых задач трансформации ассетов и обработки изображений.
